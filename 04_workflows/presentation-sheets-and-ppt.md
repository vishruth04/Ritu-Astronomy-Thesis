# Presentation sheets and PPTs

Status: Draft, 27 Nov 2026. Sources: [illustrarch](https://illustrarch.com/articles/architectural-presentation/23862-designing-presentation-sheets-tell-projects-story.html), [StudioMatrx, presenting the design](https://www.studiomatrx.org/students/interior-design-studio-2/presenting-the-design) (B); K for the rest.

## 1. Sheet basics

- Size: A1 (841 x 594 mm) or A0 for finals; A3 for reviews (her topic sheets were A3). Confirm with the guide.
- Print at 150 dpi or more; 15-20 mm safe margin.
- Same title strip on every sheet (she already has one: project | S102BPROJ | Sem 8 | name and reg no. | B.Des 2023-2027 | SIST). Add sheet number and scale.
- Grid first; one dominant element per sheet; two type sizes and two or three colours.
- Drawing conventions: scale, scale bar, north point, line weights, titles, legends.

## 2. Hierarchy and story

- One argument per sheet: problem → concept → how plan and 3D resolve it → material character.
- Plan the sequence with thumbnails before composing; order from concept to detail.
- Viewers scan in an F or Z pattern: put the key idea top-left or centre.
- Test: if a friend cannot find the concept in a few seconds, fix the hierarchy.
- Defend choices with the brief, the concept or a standard, never "I just liked it".
- Common mistakes: filling every inch, repeating near-identical views, diagrams that need decoding, beautiful sheets with an unresolved plan.

## 3. Using the concept on the sheets (K)

Let the sheets themselves go from light to dark: early sheets (site, Sun) on a white background, later sheets (stars, dome) on a deep navy/black background. Keep text contrast accessible. This makes the set itself demonstrate Chiaroscuro.

## 4. Suggested final sheet set (about 12-16 A1 sheets)

1. Title + concept statement + hero image
2. Introduction, need, user groups, KSO story
3. Literature and case-study summary (comparative table)
4. Site analysis (maps, climate, sun path, bylaws)
5. Programme, zoning, light-gradient diagram, journey storyboard
6. Concept development (sketches, models, massing)
7. Ground/lower floor plans with furniture and exhibits (1:100/1:50)
8. Sections through the light sequence (long section as the key drawing)
9. Reflected ceiling plans + lighting design
10. Sun Gallery + Spectrum Chamber: views and details
11. Moon/planets + cosmic corridor: views and details
12. Star chamber + dome theatre: views, sections, details
13. Materials and finishes board + schedule
14. Services: fire exits, emergency lighting, accessibility, HVAC/acoustics, dark-sky lighting
15. Exhibit/furniture details (1:10/1:5)
16. Views and model photos

## 5. PPT structure for reviews

10-15 minutes, 15-25 slides: title → what changed since last review → main content for this stage → decisions and reasons → questions for reviewers. One idea per slide, large images, few words. Keep a backup PDF. Export sheet PDFs at reduced size for projection.
